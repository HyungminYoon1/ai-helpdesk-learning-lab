대화 내역

    고객 메시지 확인

    현재 담당자가 직접 확인한 범위를 기록합니다. 조회만으로 확인 처리하거나 문의를 해결 상태로 바꾸지 않습니다.

    확인할 메시지를 직접 선택하세요.

    화면에 읽어 온 고객 메시지만 선택할 수 있습니다. 이후 도착한 글은 자동 확인되지 않습니다. 저장 여부 미확인 시 같은 제출로 재확인하세요. 페이지를 떠나면 선택과 제출 ID는 지워집니다.

    추가 문의 작성

    같은 문제의 경과를 남겨주세요. 독립적인 새 문제는 새 문의로 접수하면 됩니다.

    저장한 글은 담당자에게 공개됩니다. 해결 상태는 자동 변경되지 않으며, 기존 AI 요약에 추가 글이 반영되지는 않습니다.

    저장 여부가 미확인일 때는 본문을 바꾸지 말고 같은 제출로 재확인하세요. 페이지를 떠나면 작성 내용과 제출 ID는 지워집니다.

    공식 답변 작성

    저장하면 즉시 고객에게 공개됩니다. Ticket 상태는 바뀌지 않습니다. 정정은 기존 답변을 삭제하지 않고 새 답변으로 남습니다.

    저장 여부가 미확인일 때는 이 화면에서 같은 제출을 다시 확인하세요. 페이지를 떠나면 작성 중 내용과 제출 ID는 지워집니다.
